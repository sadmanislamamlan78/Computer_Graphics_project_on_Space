# Computer_Graphics_project_on_Space
# Space Shooter + Solar System

An OpenGL and GLUT computer graphics project that combines a two-player 2D space shooter with an interactive 3D solar-system viewer and a player-controlled rocket mission. The application is written as a single C++ source file, `main.cpp`.

## Features

- Intro screen and mouse-driven main menu.
- Two-player space shooter with moving saucers, lasers, aiming, life points, and a game-over screen.
- 3D solar-system viewer containing the Sun, planets, Earth's Moon, planetary rings, asteroid belt, stars, and a roaming rocket.
- Mouse-look camera with zoom, strafing, planet lock-on, animation pause, and camera reset.
- Rocket simulation with pitch, yaw, thrust, braking, visual banking, engine glow, and beacon lights.
- Five ordered rocket missions: Mercury, Mars, Jupiter, Saturn, and Neptune.
- Mission score of 100 points for each planet reached.
- Fixed 60 FPS timer for consistent animation and movement.

## Requirements

- A C++ compiler.
- OpenGL.
- GLUT or freeglut. Freeglut is recommended on Windows.
- OpenGL Utility Library (GLU).
- A windowing environment capable of creating an OpenGL context.

No external textures, models, sound files, or data files are required. All geometry, colours, lighting, and interface text are generated by the program.

## Building

### Windows with MinGW or MSYS2

Install freeglut and make sure its headers, library, and runtime DLL are available to the compiler and executable. From the project directory, run:

```bash
g++ main.cpp -o SpaceShooter.exe -lfreeglut -lopengl32 -lglu32
```

Run the program with:

```bash
./SpaceShooter.exe
```

If the linker cannot find `freeglut`, add the freeglut `include` and `lib` directories to the compiler's search paths. On Windows, place the matching freeglut DLL beside the executable or in a directory on `PATH`.

### Linux

Install the development packages for OpenGL, GLU, and freeglut. For Debian or Ubuntu-based systems:

```bash
sudo apt install build-essential freeglut3-dev
```

Compile and run:

```bash
g++ main.cpp -o SpaceShooter -lglut -lGL -lGLU
./SpaceShooter
```

### macOS

With GLUT and OpenGL available, compile with:

```bash
g++ main.cpp -o SpaceShooter -framework OpenGL -framework GLUT
./SpaceShooter
```

### Code::Blocks

1. Create a GLUT or freeglut project.
2. Replace the generated source file with `main.cpp`.
3. Configure the compiler's include and library directories for freeglut.
4. Link against freeglut, OpenGL, and GLU.
5. Build and run the project.

## How To Play

### Starting the application

The program opens on the title screen. Press **Enter** to open the main menu. Use the mouse to choose one of the following buttons:

- **Start Game**: opens the two-player shooter.
- **Solar System**: opens the 3D viewer.
- **Rocket Simulation**: opens the guided flight mode.
- **Instructions**: displays the shooter controls.
- **Quit**: closes the application.

### Space shooter

Both players can move and shoot at the same time. Each player starts with 100 LIFE. A successful laser hit removes 5 LIFE. The player whose opponent reaches zero LIFE wins.

| Player | Move up | Move down | Move left | Move right | Shoot |
| --- | --- | --- | --- | --- | --- |
| Player 1 | `W` | `S` | `A` | `D` | `C` |
| Player 2 | `I` | `K` | `J` | `L` | `M` |

Hold the shoot key together with the player's up or down key to angle the laser.

### Solar-system viewer

| Input | Action |
| --- | --- |
| Hold left mouse button and drag | Look around |
| `W` / `S` | Zoom in / out |
| `A` / `D` | Strafe left / right |
| `1` to `9` | Lock the camera to Mercury through Pluto |
| `0` | Unlock the camera |
| `R` | Reset the camera |
| `T` | Toggle the roaming rocket's self-rotation |
| Spacebar | Pause / resume planetary and asteroid motion |
| `Q` or `Esc` | Return to the main menu |

### Rocket simulation

Fly the rocket close to each target planet in the order shown by the mission display. The simulation awards 100 points per completed mission.

| Input | Action |
| --- | --- |
| Up / Down arrow | Pitch the rocket |
| Left / Right arrow | Yaw and visually bank the rocket |
| `W` | Apply thrust |
| `S` | Brake |
| `1` | Toggle the red beacon |
| `2` | Toggle the green beacon |
| `3` | Toggle the blue beacon |
| `R` | Reset the rocket, missions, and beacon lights |
| `Q` or `Esc` | Return to the main menu |

## Technical Notes

- The 2D screens use an orthographic projection.
- The Solar System and Rocket Simulation use perspective projection, depth testing, lighting, and GLU camera helpers.
- The application requests a double-buffered RGB window with a depth buffer.
- Keyboard state is polled every frame so movement, thrust, braking, and turning remain smooth while keys are held.
- The initial window size is 1200 x 600 pixels and the view adapts when the window is resized.

## Troubleshooting

**Header not found:** Install GLUT/freeglut development files and add their `include` directory to the compiler configuration.

**Linker errors for OpenGL or GLUT:** Confirm that the platform-specific libraries are linked and that 32-bit/64-bit library versions match the compiler.

**The executable starts but reports a missing DLL on Windows:** Copy the matching freeglut DLL next to the executable or add its directory to `PATH`.

**The window is blank or the 3D view behaves incorrectly:** Use a graphics driver with OpenGL support and confirm that the program was linked with a depth-buffer display mode.
